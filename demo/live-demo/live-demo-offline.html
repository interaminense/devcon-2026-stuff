Before you start
  1. Start the container. If Docker itself is not running, start it first with systemctl --user start docker.

  1. Open the site at devcon.localhost:8081, never at localhost:8081: the two share cookies with the other local DXP and sign you out.
  2. Open Offline Test once: if both cards show numbers and a chart, offline mode works.

Prepare the page

  1. Site menu → Design → Fragments → new set DEVCON Demo → new fragment LDP Fragment Card, with the code of topic 1.
  2. Site menu → Pages → New → Page → Blank, named Demo.
  3. In the page editor, drag Offline Mode (set DEVCON Offline) to the top of the page first, then the LDP Fragment Card below it, and publish.

Offline Mode answers the LDP and AI Hub calls with fake data; it shows a dashed label only in the editor. It must stay above the cards. The code is the same as on stage, so CHANNEL_ID and AGENT_ERC are ignored here. The Insight Alert object, the Marketing Team role, the notification and Bruna are real.

Reset the Rehearsal

Start over
  1. Site menu → Pages → Demo → ⋮ → Delete.
  2. Site menu → Design → Fragments → DEVCON Demo → ⋮ → Delete.
  3. Control Panel → Insight Alerts: delete the alerts the rehearsal created.

Keep the DEVCON Offline and Offline Test sets, the Offline Test page, the Insight Alert object, the Marketing Team role and Bruna.

Stop the DXPdocker stop devcon-dxp
