Build a Custom Dashboard

Topic 04
  1. In the editor
  2. In the UI

    Ship version 4

    1. Tab 3: Design → Fragments → DEVCON Demo → LDP Fragment Card → ⋮ → Edit.
    2. Paste the code above into the JavaScript, CSS and Configuration tabs → Publish.
    3. ⋮ → View Usages → select all → Propagate. Pages keep their copy of the fragment until you propagate.
    4. Demo page → reload.
  3. In the UI

    Build the dashboard

    1. Edit the Demo page.
    2. Components panel → Fragments → Layout Elements → drag a Grid under the first one. Set Number of Modules to 3. Repeat for a third row.
    3. Drag an LDP Fragment Card into each new module.
    4. Select each card → General → Widget, as below. Time range is per card too (Last 24 hours to Last 90 days); check that the Widget did not change when you set it → Publish.
    Row 1Unique visitors · Sessions per visitor
    Row 2Sessions · Session duration · Bounce rate
    Row 3Top pages by views · Acquisition by channel · Visitors by device
  4. In the UI
    1. Any card → ✦ AI insight. Lists work too: the card sends its top items.
