Live Demo Guide

Today we're going to build a custom dashboard right inside DXP, using the Liferay tools you already have. We keep the flow simple on purpose: easy to follow, and easy to build yourself.

Diagram Flow

DXPLDPAI Hub

  1. 1Client Extensions puts <ldp-demo-card> on the page, pointing to the card’s JS URL.
  2. 2The browser loads the card code from Documents and Media.
  3. 3The card asks the LDP proxy for its metric. DXP forwards the GraphQL query to LDP.
  4. 4The card loads and saves its metric in the Objects API, one entry per widget instance.
  5. 5The card asks DXP for an AI Hub token. DXP signs in with the Client ID and Secret.
  6. 6The card sends its numbers to the AI Hub agent. The LLM writes the insight shown under the chart.

Animated Walkthrough

1

Setup

Upload ldp-demo-card.js to Documents and Media, then register it in Client Extensions with its JS URL.

2

Page

DXP renders the demo page with two ldp-demo-card widgets and a script tag for the JS URL.

3

Script

The browser loads the card code from Documents and Media. Each widget becomes a live card.

4

Metric

Each card asks the LDP proxy, with the user's session. DXP forwards the GraphQL query to LDP and returns value, previous value and trend.

5

Config

Each card saves its metric in Objects, keyed by its widget instance. After a reload, every card remembers its own setup.

6

Token

DXP signs in to AI Hub with the Client ID and Secret, and hands the card a short-lived token.

7

Insight

The card calls the AI Hub agent directly. The LLM runs the prompt, and the insight shows up under the chart.

All

The full picture

Reset the demo

Start over
  1. DEVCON Demo → Site Builder → Pages → Demo → ⋮ → Delete. Keep Home.
  2. Applications → Client Extensions → LDP Demo Card → ⋮ → Delete.
  3. DEVCON Demo → Documents and Media → ldp-demo-card.js → ⋮ → Move to Recycle Bin.
  4. DEVCON Demo → Recycle Bin → Empty the Recycle Bin. Otherwise the next upload gets a different URL.
  5. Control Panel → Objects → folder DEVCON Demo → Demo Card Config → ⋮ → Delete. Its entries go with it.
  6. AI Hub → Agent Builder → DevCon 2026 Demo LDP Metric Insight → ⋮ → Delete, so its external reference code is free again.
  7. In the editor, empty ldp-demo-card.js.
