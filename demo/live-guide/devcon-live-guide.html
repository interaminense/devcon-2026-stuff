How the card works

  1. 0

    Setup part 2

    Documents and Media → File UploadClient Extensions → Custom Element

    You upload ldp-demo-card.js and register it with its URL, ?v=N and Instanceable. Each upload needs a new ?v=N.

  2. 1

    Page part 2

    GET /web/devcon-demo/demo

    DXP renders the page with <ldp-demo-card> and a <script> pointing at the registered JavaScript URL.

  3. 2

    Script part 2

    GET /documents/d/devcon-demo/ldp-demo-card-js?v=N

    Documents and Media serves the file as JavaScript; customElements.define starts every instance.

  4. 3

    Metric parts 3–4

    POST /o/analytics-rest/v1.0/graphql

    Same origin: the session and x-csrf-token are the auth. DXP forwards site(channelId, rangeKey: 7) to LDP with the workspace token and returns value, previousValue and trend.

  5. 4

    Config part 5

    GET …/democardconfigs/by-external-reference-code/{id}PUT same URL { metric }

    One entry per widget instance, keyed by its portlet id. 404 means never configured; PUT creates, then replaces.

  6. 5

    Token part 6

    POST /o/ai-hub-cell/v1.0/authorization-tokens

    DXP uses the Client ID and Secret on the server and hands the card accessToken, userToken and serviceURL.

  7. 6

    Insight part 6

    GET {serviceURL}/o/ai-hub/v1.0/agent-instances/subscribePOST {serviceURL}/o/ai-hub/v1.0/agent-instances

    The card talks to AI Hub directly (cross-origin, allowed by the Environment URL): it opens an event stream, starts the agent with { metrics }, and the insight comes back as the event DEVCON_2026_DEMO_LDP_METRIC_INSIGHT.

Topic 05
  1. In the UI

    Connect DXP to AI Hub

    1. Tab 6: AI Hub → the account configuration → copy the Client ID and the Client Secret.
    2. In the same configuration, check the Environment URL: the DXP address below, with no slash at the end.
    3. Tab 2: Control Panel → Instance Settings → Platform → AI Hub → paste the values → Save.
    FieldValueWhat it does
    Client IDCopied from AI HubIdentifies this DXP to AI Hub.
    Client SecretCopied from AI HubProves it. It stays on the DXP server and never reaches the browser.
    Service URLhttps://na1.hub.liferay.comWhere the AI Hub of this region lives. DXP asks it for tokens.
    Environment URL (in AI Hub)https://webserver-lctacdemodevcon-prd.lfr.cloudThe DXP origin AI Hub trusts: it allows the browser calls (CORS) and calls DXP back on the user’s behalf. Must match exactly, no trailing slash.
  2. Heads up

    The projector shows everything: paste the Client Secret with the screen mirrored off, or show the field already filled. If the secret was shown, generate a new one after the talk.

  3. Say

    DXP keeps the secret. The browser only gets a short-lived token from DXP, and AI Hub acts on behalf of the signed-in user.

  4. Say

    An AI Hub agent is an agent definition plus a workflow with an LLM node. The card sends what it shows; AI Hub never reads LDP itself.

  5. In the UI

    Create the agent

    1. Tab 6: AI Hub → Agent Builder.
    2. Make Shorter → ⋮ → Duplicate.
    3. On the copy: ⋮ → View → fill in the fields below → Save.
    FieldValueWhat it does
    TitleDevCon 2026 Demo LDP Metric InsightThe name people see in Agent Builder.
    DescriptionTurns one LDP metric from the DEVCON demo card into a short insight.Tells people, and the AI Hub assistant that picks agents, what this agent is for.
    External reference codeDEVCON_2026_DEMO_LDP_METRIC_INSIGHTThe agent’s fixed address. The card starts the agent with it, and the answer comes back on an event with this name.
    Input variablesmetricsThe names of the values the caller sends. The card sends its summary as metrics.
    Output variableinsightWhich workflow output is the agent’s answer. Must match the node’s output variable.
  6. Say

    The external reference code is the agent’s address. It is the only thing the card needs to know about it.

  7. In the UI

    Write its workflow

    1. View Workflow → click the LLM node in the middle.
    2. In the panel on the right, fill in the fields below → Update.
    FieldValueWhat it does
    Node NameldpMetricInsightThe node’s id inside the workflow. It also comes back in the answer as nodeName.
    Input variables[{"name":"metrics","type":"string"}]The values this node reads. Only these are replaced as {{name}} in the prompt and the user message.
    Output variables[{"name":"insight","type":"string"}]Where the node stores the model’s reply.
    PromptYou are an analytics assistant. You receive one website metric from Liferay Data Platform: its name, the period, the value, the previous period's value, and the change. Write at most three short sentences for a marketing manager: what the number says, how it compares with the previous period, and one concrete action. Plain text only. Never invent numbers. If there is too little data, say so in one sentence.The system message: the model’s role, the rules, and the shape of the answer.
    User messageMetric summary: {{metrics}}The message the model answers. {{metrics}} becomes the text the card sent.
    Tools[]Tools the model may call, such as MCP servers. None here; must be [], never empty.
    RAG{}Documents the model may search before answering. None here; must be {}, never empty.
  8. Heads up

    Never leave Tools or RAG empty: the save fails with “Unable to parse definition”. After Update, open Source once and check that <prompt> still has the text; an empty prompt saves fine, but the agent never answers.

  9. Say {{metrics}} is replaced by the text the card sends. Only the node’s input variables are replaced.

Reset the demo

Start over
  1. DEVCON Demo → Site Builder → Pages → Demo → ⋮ → Delete. Keep Home.
  2. Applications → Client Extensions → LDP Demo Card → ⋮ → Delete.
  3. DEVCON Demo → Documents and Media → ldp-demo-card.js → ⋮ → Move to Recycle Bin.
  4. DEVCON Demo → Recycle Bin → Empty the Recycle Bin. Otherwise the next upload gets a different URL.
  5. Control Panel → Objects → folder DEVCON Demo → Demo Card Config → ⋮ → Delete. Its entries go with it.
  6. AI Hub → Agent Builder → DevCon 2026 Demo LDP Metric Insight → ⋮ → Delete, so its external reference code is free again.
  7. In the editor, empty ldp-demo-card.js.
